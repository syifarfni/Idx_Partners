# Credit Risk Prediction Model 

Model prediksi risiko kredit yang dikembangkan selama program Virtual Internship ID/X Partners x Rakamin Academy.

---

## Tentang Proyek

Proyek ini bertujuan untuk membantu perusahaan pemberi pinjaman dalam mengambil keputusan kredit yang lebih akurat dengan memprediksi apakah seorang peminjam termasuk kategori berisiko atau tidak.

Dataset yang digunakan terdiri dari 466.285 data historis peminjaman dengan 75 fitur yang mencakup informasi finansial, histori kredit, dan profil peminjam.

---

## Proses Pengembangan

Tahapan yang dilakukan dalam proyek ini meliputi:

- Data cleaning dan penanganan missing values
- Penentuan target klasifikasi `good_bad`
- Pembagian data training dan testing (80:20)
- Preprocessing dan standarisasi tipe data
- Pelatihan model menggunakan Logistic Regression
- Evaluasi performa menggunakan ROC Curve dan accuracy score

---

## Hasil Model

Model berhasil mencapai akurasi sebesar **88%** pada data pengujian. 

Berdasarkan evaluasi ROC Curve, model mampu membantu mengidentifikasi calon peminjam dengan risiko tinggi secara lebih efektif, sehingga dapat mendukung pengambilan keputusan kredit yang lebih aman dan terukur.
